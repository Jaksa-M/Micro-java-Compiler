# MicroJava Compiler

A compiler for MicroJava, a small Java-like language used for teaching. It takes a `.mj` source file and produces bytecode for the MicroJava virtual machine. Written in Java for the Compiler Construction 1 course at the School of Electrical Engineering in Belgrade (January 2025 term).

## How it works

1. **Lexer**: generated by JFlex from `spec/mjlexer.flex`.
2. **Parser**: generated by CUP from `spec/mjparser.cup`. It builds an AST and recovers from some syntax errors so it can report more than one per run.
3. **Semantic analysis**: `SemanticAnalyzer.java` walks the tree, fills the symbol table and checks types, declarations and how names are used.
4. **Code generation**: `CodeGenerator.java` walks the tree again and emits bytecode.

Errors are reported with line numbers at every stage. If anything fails, no object file is written.

## Supported language

- `int`, `char`, `bool`, constants, global and local variables, arrays
- methods with parameters and return values
- `if` / `else`, `do`-`while` with `break` and `continue`
- conditions with `&&` and `||`
- `read` and `print`
- sets, with a `union` operator, and a `map` expression that applies a function to each array element

Classes and interfaces are not supported. The keywords are recognised by the lexer, but there are no grammar rules for them.

## Layout

```
spec/     lexer and grammar specifications
src/      analyzer, code generator and generated parser sources
test/     MicroJava test programs and the compiler entry point
lib/      JFlex, CUP, symbol table and the MicroJava runtime
config/   log4j configuration
```

## Running

The repo is an Eclipse project with an Ant build file.

```
ant compile
```

regenerates the lexer and parser and compiles the sources. The entry point is `test/rs/ac/bg/etf/pp1/MJParserTest.java`. It expects two arguments, but for now the paths are hard-coded: it always reads `test/program.mj` and writes `test/program.obj`.

To see the generated bytecode and then run it on the MicroJava VM:

```
ant runObj
```

Program input comes from `test/input_file.txt`. `test301.mj`, `test302.mj` and `test303.mj` are sample programs. To try one, copy it over `test/program.mj`.

The language specification and the assignment, in Serbian, are in `Project Description and Setup/`.
